## ✨ Frontend Design Direction (2026)

The documentation site uses a **retro-futuristic** aesthetic: dark navy base with cyan and blue accents, no purple gradients. The look follows the [Frontend Design Guidelines](../.agents/skills/frontend-design/SKILL.md) for a memorable, production-grade experience.

**Key design features:**

- **Aesthetic:** Dark background, subtle grid overlay, and cyan/blue glows for a focused, technical tone.
- **Typography:**
   - Display: [Orbitron](https://fonts.google.com/specimen/Orbitron) (sci-fi, geometric)
   - Body: [IBM Plex Mono](https://fonts.google.com/specimen/IBM+Plex+Mono) (technical, monospaced)
- **Color palette:**
   - Dark navy (#0f1419, #1a2332), cyan (#00ffe7), electric blue (#2f80ff), yellow (#ffe600) for focus/highlights
   - No purple or magenta; accents are cyan and blue only
- **Layout:**
   - Card layout for bookmarklets with clear hierarchy
   - Animated page load with staggered reveal
   - Generous spacing and grid overlay
- **Motion:**
   - Subtle grid overlay
   - Cyan glow on title accent and links
   - Smooth transitions (ease-out)

This direction keeps the site distinctive and avoids generic "AI slop" (e.g. purple-to-blue gradients). For details, see [frontend-design.md](../.agents/skills/frontend-design/SKILL.md).
