# Bypass article paywall

Sends the current page URL through `1ft.io`, a proxy service that fetches and re-renders article content. This is sometimes enough to bypass soft paywalls or overlay-heavy pages.

## Usage

1. Install the bookmarklet: drag it from the [collection site](https://diegofleitas.github.io/bookmarklet-collection/) into your bookmarks bar, or create a new bookmark and paste the code from `index.js` as the URL.
2. Visit an article page with a paywall.
3. Click the bookmarklet. The page reloads via `1ft.io`.

## Notes

> [!WARNING]
> This relies entirely on `1ft.io`; if the service is down or changes its behavior, the bookmarklet stops working. Always respect site terms of use and support publishers you value.
