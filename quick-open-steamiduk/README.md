# Quick open SteamID UK

Speeds up SteamID UK indexing by automatically opening each Steam profile link on the results page in a new tab for a few seconds, then closing it. This signals the profiles to the indexer without requiring manual clicks.

## Usage

1. Install the bookmarklet: drag it from the [collection site](https://diegofleitas.github.io/bookmarklet-collection/) into your bookmarks bar, or create a new bookmark and paste the code from `index.js` as the URL.
2. Use the SteamID UK bulk player finder and navigate to the results page.
3. Click the bookmarklet and let the browser cycle through tabs automatically.

## Notes

> [!WARNING]
> Opening many tabs rapidly may be blocked by your browser's pop-up policy; allow pop-ups for the site if needed. This puts extra load on Steam and SteamID UK; use sparingly and only where permitted.
