## Overview

This bookmarklet speeds up indexing new players from the results page of the **SteamID UK bulk player finder** website.

When run on the results page, it finds Steam profile links (`https://steamcommunity.com/profiles/[SteamID]`) that are not inside a table, opens each profile in a new tab for a few seconds, and then closes the tabs. This helps SteamID UK detect and import player data more quickly.

## Usage

1. Create a new bookmark in your browser.
2. Paste the bookmarklet JavaScript as the bookmark's URL.
3. Use the SteamID UK bulk player finder as usual and navigate to the results page.
4. Click the bookmarklet.
5. Let the browser open and close tabs automatically while the script runs.

## Notes

> [!WARNING]
> Opening many tabs at once may be blocked or throttled by your browser; you might need to allow pop‑ups. This behavior can put extra load on Steam and SteamID UK—use it sparingly and only where permitted.
